# 商品与成本表格导入

在“前端商品库”和“产品成本库”页内均可下载Excel空白模板和填写示例。示例使用EXAMPLE编码，不会自动进入正式资料。先替换为自己的商品，再上传、预览并确认。

## 前端商品

支持xlsx、xls、csv，选择工作表、表头行及字段对应列，按平台SKU新增或更新。新增商品必须有平台SKU、商家SKU、商品名称。更新时只填写需要修改的字段，空白不覆盖已有值。

| 字段 | 填写方式 |
| --- | --- |
| 平台SKU | 完整文本，不能用科学计数法；同一文件不可重复 |
| 商家SKU | 用于自动关联产品成本库 |
| 商品名称、销售链接 | 名称及http/https商品链接 |
| 套装类型 | 已在成本库建立的类型名称，安装版兼容为安装板 |
| 链接类型 | 正常链接、国补链接、百补链接 |
| 关联成本SKU | 可选；指定另一条已存在的成本库货品 |
| SKU基础成本（元） | 仅覆盖此销售SKU的基础采购成本，公共成本库不变；不包含额外运费或套装附加成本 |
| 平台扣点（%） | 此SKU独立扣点；5.9或5.9%表示5.9%，同时识别Excel百分比格式 |
| 生效日期 | 可选，默认使用导入弹窗指定日期 |
| 对应关系核实 | 已核实或待核实；对应关系改变时默认重新待核实 |

独立基础成本或扣点填0时按明确的0处理；填“跟随”分别恢复成本库或链接类型规则。没有提供独立扣点时保持已有规则，新商品按类型费率计算；类型费率没有维护则显示待补。

未建立的套装、错误费率、重复SKU或非法链接会阻止整批保存，并提示源行号。新增商家SKU自动建立待补成本记录；不会根据商品名称猜测成本。自定义类型先在产品成本库建立，并设置实际附加成本。

## 产品成本

支持xlsx/xls，工作表名称保留“成本校对”。模板字段为商家SKU、采购成本、运费规则、运费、其他单件费用，金额单位元。另计运费、无额外运费、已含运费是独立规则，后两种情况不再叠加运费。

同时支持原云表无表头布局：从第1行取A列商家SKU、C列采购成本、E列运费。会显示列映射供核对。原表导入默认启用并明确展示：空白运费按0、跳过空采购成本、跳过没有商家SKU的参考行。预览分别列出跳过数量，不按名称猜测匹配。

导入按商家SKU追加带生效日期的成本版本，保留原记录、来源文件、工作表、行号与导入指纹；相同文件及设置不会重复保存。采购成本取Excel已保存结果，未重新执行文件中的任意公式。

## 保存

确认导入先保存为当前浏览器草稿；完成核对后使用“发布到GitHub”留存到仓库。上传原文件不自动归档，只保留解析后的白名单字段。Excel模板“填写说明”页不作为商品或成本数据导入。

重新打开网站时，无未发布更改的本机资料会跟随GitHub最新版本；有未发布草稿则保留并提示有新版本，先备份再载入。
